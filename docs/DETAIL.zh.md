输入框工具行多一个分支按钮：点开是当前仓库的分支菜单，选中即原地切换；空白会话再勾选「工作树」，新会话就落进仓库内的独立 Git 工作树，与主检出互不干扰。

## 你可以这样用

- **看分支、切分支**：本地与远程分支分组展示，`/` 按文件夹层级折叠，行上箭头标出与上游的领先/落后。选中即切换（免确认）；选远程分支直接检出并自动建跟踪。
- **分支上的操作**：右键任意分支行——签出、新建、从它新建并检出、重命名、删除、复制；当前分支可快进更新到上游，或打开紧凑的推送窗口（待推送清单、Git 标记、force-with-lease，远程校验通过后才能推）。
- **看提交历史**：菜单旁的图谱按钮原位展开提交图谱：浏览不检出，选中看作者、时间、正文与文件摘要；滚到底自动加载，可按标题或哈希搜索。
- **隔离进工作树**：空白会话勾选「工作树」（或右键分支行「创建工作树」），会话在 `<repo>/.dsh/gitworktree/<分支>` 开始并注册为真实工作区，重复创建复用已有目录；被占用的分支收进「工作树」分组，「跳到此工作树」直接进去开新会话。新分支名留空即自动生成 `<基分支>-<4位十六进制>`。
- **想留在同一个工作区也行**：开启「在当前工作区下切换工作树目录」后，工作树改为在所属仓库下切换会话目录（同 DSH 官方方式）；新建工作树延迟到发送首条消息时才执行，失败可「重试」或「不使用工作树继续」。
- **一键检出 PR / MR 到隔离工作树**：从可选 Forge 候选列表直选，或输入编号 / 链接，直接拉取 `refs/pull/<id>/head` 或 `refs/merge-requests/<id>/head` 到独立工作树，不动主检出；已有 PR 工作树可直接打开或一键同步最新（干净工作树遇远端 force-push 自动同步，有本地提交时先确认不静默覆盖）。
- **同步远程**：工具栏刷新按钮 fetch 全部远程并清理失效跟踪分支；推送、更新期间有可取消的悬浮进度卡片，切换会话也在。

## 一些边界

- 会话开始后目录固定；工作树会话的分支菜单只显示自己的分支，其余操作请回主仓库发起。
- 「删除工作树」会先列出未提交文件数与领先提交数，确认后删除 git 工作树、归档其会话并注销工作区——分支本身保留；有会话正在运行时不可删。
- 所有 git 操作由插件在会话之外执行；绝不替你 stash、改写历史或动主检出的文件。
- 设置 → 插件里本插件的配置页可打开跨仓库的工作树管理弹窗；也可一并纳管 `<repo>/.agents/worktrees` 下的 DSH 官方工作树，它们永不参与自动清理。
- 插件默认隐藏空白会话右上角 DSH 官方的新建工作树按钮，保持单一入口；在设置中关闭「接管官方新建工作树入口」即可恢复。
