# DR: 图谱上沿避开宿主顶栏

Status: implemented

## Problem

图谱浮层挂在 `document.body` 上，按视口顶端留 12px 向上生长。未开始会话时输入框在画面中部，700px 上限会一直顶到窗口最上面，盖住 DSH 的顶部导航栏。会话进行中输入框靠近底部，同样的高度通常碰不到顶栏，所以这个问题只在未开始会话时明显。

## Decision

本记录部分取代[分支图谱保持按钮锚点原位展开](2026-10-18-branch-graph-anchor-placement.md)的上沿算法，底边、宽度和最大高度 700px 不变。

图谱上沿不得进入宿主窗口顶栏。顶栏高度读取宿主已经公布的 `--dsh-frame-chrome-top`（全屏时宿主把它写成 0）；该值未设置时改读 `--dsh-frame-top-clearance`（macOS 交通灯区域的静态留白）。两者都没有或不是数字时视为没有顶栏。上沿在顶栏下沿之外再留原来的 12px。顶栏变高、全屏或窗口尺寸变化时按同一次测量重算，并取消正在进行的展开动画。

普通分支菜单仍只受视口边缘约束，不套用这道顶栏留白。

## Alternatives considered

**写死顶栏像素**：Windows 标题栏高度由宿主变量决定，全屏时变为 0，固定像素会在一种状态下留出空带、在另一种状态下继续盖住顶栏。

**改用对话容器的上沿**：未开始会话时该容器往往从视口顶端排起，读到的仍是 0，盖住顶栏的问题还在。输入框卡片的上沿更不能用，那会把图谱重新抬离分支按钮。

## Consequences

未开始会话时图谱停在顶部导航栏下面，顶栏和窗口拖拽区保持可点。可用高度比原来少一个顶栏加 12px，列表更早出现内部滚动。没有这些变量的宿主行为与改前相同。全屏时顶栏高度为 0，图谱可以再次贴近视口顶端 12px。
