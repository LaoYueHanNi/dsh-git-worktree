# DR: 分支图谱保持按钮锚点原位展开

Status: implemented

## Problem

图谱初版将普通分支菜单和图谱都抬到输入框卡片顶部以上，并对图谱增加视口垂直居中。输入框变高或视口较高时，浮层与分支按钮之间出现大段空隙，普通菜单也偏离原有的按钮左下角锚定方式。用户要求普通菜单恢复原位，图谱由同一弹窗向上、向两侧扩大，宽度不超过对话框。

## Decision

本记录部分取代[从分支菜单原位展开提交图谱](2026-10-18-branch-commit-graph.md)中的浮层定位规则，其余图谱行为继续沿用。

普通菜单左边缘对齐分支按钮左边缘，下边缘距按钮顶部 6px，并保留视口边界约束和自适应菜单高度。展开图谱保持同一下边缘，横向对齐所属输入框卡片中心，宽度不超过卡片实测宽度、1060px 和视口可用宽度。图谱从该底边向上增长，高度最大 700px，同时在视口顶部保留 12px；上方空间不足时缩短并内部滚动。

输入框卡片只提供图谱横向尺寸约束，不再提供纵向避让边界，也不再将图谱垂直居中。因此浮层可以覆盖按钮上方的输入框正文区域，按钮及底部操作仍位于浮层下方。展开、收起沿用 220ms ease 动画；窗口、侧栏或输入框尺寸变化时重新测量，取消旧动画，底边继续跟随分支按钮。

## Alternatives considered

**视口垂直居中**：初版用于缓解新会话上方空间不足，但高视口下会使浮层与触发按钮分离，不符合本轮明确要求。

**始终避让整个输入框卡片**：初版用于保证整个输入区可见，但多行输入、任务栏和底部工具行会拉大浮层到按钮的距离。改为保留按钮锚点，接受临时遮挡按钮上方区域。

## Consequences

普通菜单恢复既有位置，图谱以同一个按钮为起点展开，输入框高度变化不再凭空增加两者间距。图谱仍受实际对话宽度和视口上边界约束；新会话居中输入框上方空间较少时，图谱列表高度会缩短，需要内部滚动。输入框正文可被浮层临时遮挡，关闭浮层后恢复完整可见。
